# Large release assets

Do not commit large binary artifacts to normal Git history.

Recommended GitHub Release / Zenodo assets:

- `SRACR_Med_R1C11_Model_Checkpoints.zip`
- the full machine-readable reproducibility archive
- archived v7.3 feature caches

Raw medical images should not be redistributed.

Recommended release:

- Tag: `v1.0.0`
- Title: `SRACR-Med v1.0.0 - manuscript reproducibility release`

After publishing the GitHub Release, archive that release on Zenodo and add the issued DOI to `CITATION.cff` and to the paper's Data and Code Availability statement.
